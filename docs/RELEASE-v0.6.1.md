# Gael 0.6.1 - A tiny lightning companion

Four glowing energy forms, English chat and voice, source-linked game guidance, and playful desktop flights for Windows.

## What's new

After 20 seconds without interaction, Gael takes a 7-second flight and returns to his starting position. Disable or preview adventures from the right-click menu. Interaction, mute, hide, and reduced motion interrupt flight.

## Downloads

- `Gael-0.6.1-Windows-x64.zip`: portable executable and quick-start instructions.
- `Gael-0.6.1-portable.exe`: standalone portable executable.
- `SHA256SUMS.txt`: checksums for downloadable files.

Extract the ZIP and run the EXE. No Node.js installation required. Windows x64; unsigned application. Close older instances first.

AI chat, guide search, and transcription require your own OpenAI API key with API credit. Local tips and animation work without a key. Use borderless windowed games. Gael does not see your game screen or automatically track your progress.
