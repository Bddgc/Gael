# Contributing

Use English for issues, pull requests, documentation, and user-facing text.

1. Create a branch for a focused change.
2. Use Node.js 24 LTS and run `npm ci` on Windows.
3. Run `npm test` after changing code.
4. For desktop changes, test dragging, tray controls, reduced motion, and the assistant panel with `npm start`.
5. Explain the problem, resulting behavior, and validation in your pull request.

Do not commit secrets, personal settings, guides, binaries, node_modules, backups, or validation captures. Mock paid API calls in automated tests. Use GitHub private vulnerability reporting for sensitive findings if enabled; never post secrets publicly.

No open-source license has been selected. Clarify licensing with the owner before redistributing code or artwork.
